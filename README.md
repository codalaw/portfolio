# Cody Lawson | Portfolio

My personal portfolio website, built to introduce myself, share my projects, and document my progress as I learn web development.

## About

I’m a hands-on learner working with HTML, CSS, JavaScript, and Python. This portfolio gives me a place to put those skills into practice and share what I build along the way.

## Features

- Responsive layout for desktop, tablet, and mobile
- Introduction with a headshot and decorative code card
- About section with the skills I’m learning
- Project showcase with links to live demos and source code
- Email, GitHub, and LinkedIn contact links
- Keyboard focus styles and a skip-to-content link
- Support for reduced motion preferences

## Built With

- HTML5
- CSS3
- CSS Grid and Flexbox
- CSS custom properties
- Media queries

The current site does not require JavaScript or any external dependencies.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/codalaw/portfolio.git
```

Open the project folder and launch the main HTML file in your browser, or use a local preview extension in VS Code.

No installation or build step is required.
